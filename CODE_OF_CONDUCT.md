# Contributor Covenant Code of Conduct

We pledge to make participation in this project harassment-free and respectful for everyone. Unacceptable behavior includes harassment, discrimination, threats, and publishing private information without permission.

Report concerns privately through the project's GitHub Security Advisories. Maintainers will review reports promptly and limit disclosure to what is necessary to resolve them.

This policy is adapted from the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
